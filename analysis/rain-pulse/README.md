# Rain pulse

Question: does a rain day after dry days change the night-time ecosystem respiration (Reco), the net ecosystem exchange (NEE) and the gross primary production (GPP) in the next days, and does the soil water content (SWC) before the rain change the size of this pulse? Article: https://inar.rjuho.dev/deep-dive/rain-pulse/

Data: the harmonised database snapshot of 2026-10-23 (`builtAt` 2026-10-23T19:03:07.928Z): `db/sites.parquet`, `db/variables.parquet`, `db/observations.parquet`, `db/events.parquet`, and `data/calculated/fluxes_30min.parquet` (calculated products of the same snapshot, `built_at` 2026-10-23T19:03:09.003Z). The release asset `db-2026-10-23.zip` is not yet published (TODO). The script docstring gives the SHA-256, the row count and the columns of each input file. The script uses no literature value; `LITERATURE` holds the Lloyd–Taylor constants and the u* limit of `docs/calculated.md`.

Method in short: daily rain per local day (40 or more rain half hours; Haltiala uses the Viikki rain). An event = a day with rain ≥ 2, 5 or 10 mm after three days below the same threshold, followed up to day 15 until the next rain day, a day without a rain value or the end of the season (Finnish sites: May to September; Maktau: all year). Events near a harvest, cut, grazing, tillage or sowing are dropped; at Haltiala, the SWC must rise by 0.01 m³ m⁻³ or more. Daily responses from the measured half hours: night NEE divided by a Lloyd–Taylor soil temperature model (fit per site-year), hour-weighted daily NEE, and daily GPP. Each event is normalised by its own mean of days −3 to −1 (ratio for Reco and GPP, difference for NEE). The full rules are in the `METHOD` part of the script docstring and in `results.json` (`method.rules`).

Figures (`figures/`): 1 `1-reco-lag.svg`, 3 `3-nee-lag.svg`, 5 `5-gpp-lag.svg`: mean of the events per site and day since the rain day, three thresholds, ± 1 SE band for 5 mm, days with fewer than 5 events not drawn. 2 `2-reco-swc.svg`, 4 `4-nee-swc.svg`, 6 `6-gpp-swc.svg`: pulse (mean of days 0 to 2) of each 5 mm event against the SWC of day −1 minus the site median, with an OLS line, Pearson r and Spearman ρ.

Run (from the repository root): `uv run analysis/rain-pulse/rain-pulse.py --db db --calculated data/calculated`; check against the committed results: add `--check`.

Develop: `uvx ruff@0.17.2 format analysis/rain-pulse && uvx ruff@0.17.2 check analysis/rain-pulse`, `uv run --with pyright==1.1.414 --with pytest==9.1.1 --with-requirements analysis/rain-pulse/rain-pulse.py pyright analysis/rain-pulse`, `uv run --with pytest==9.1.1 --with-requirements analysis/rain-pulse/rain-pulse.py pytest analysis/rain-pulse/`.
